# flux_configs

Three small JSON files with model-architecture hyperparameters (scheduler, transformer, VAE), in the format the `diffusers` library reads, so the optional FLUX.1 Kontext pipeline can be built without contacting Hugging Face.

They describe the architecture of **FLUX.1 Kontext [dev]** by Black Forest Labs, whose model weights and related files are released under the **FLUX.1 [dev] Non-Commercial License**. The weights are **not** included here; you must download them yourself and accept that license. These configs are listed so you know their origin. Do not use the FLUX model for commercial purposes unless you hold a license that allows it.

This folder is part of the optional `ai_backend`, not of the AZRA application.
