# Bundled environments

These three 1024x512 Radiance `.hdr` environments are **generated by code**
(`tools/gen_default_content.py`): a procedural three-light studio on a grey sweep. No photograph and
no third-party image was used, so they carry no third-party license; they are covered by the
repository's AGPL-3.0-or-later license.

| File | Look |
|---|---|
| `neutral_dark_0.003.hdr` | Balanced studio. **Loaded as the default environment.** |
| `environment_dark_gradient.hdr` | Dark, low-key gradient. Fallback if the default is missing. |
| `studio_bright_softbox.hdr` | Bright high-contrast softbox lighting. |

The first two file names are historical and kept because the application looks them up by name;
the content is not "dark" or "0.003" in any literal sense.

Regenerate with `python tools/gen_default_content.py` (needs `numpy` and `Pillow`).
