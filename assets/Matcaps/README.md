# Bundled matcaps

These 25 matcaps are **generated by code** (`tools/gen_default_content.py`): a procedural studio
environment shaded onto a sphere. No photograph and no third-party image was used, so they carry
no third-party license; they are covered by the repository's AGPL-3.0-or-later license.

Regenerate them with `python tools/gen_default_content.py` (needs `numpy` and `Pillow`).

You can add your own `.png` matcaps to this folder. Only add images whose license allows
redistribution.
