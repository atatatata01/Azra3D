v3 Changes

Eye Icon Everywhere

Consistent SVG eye in every row — open eye = visible, closed eye with slash = hidden. Always aligned in a fixed 28px column. No dots.

Shader Tree = Own Tab

Clicking "Shading" tab switches entirely to the MODO-style shader tree with Name / B / % / Effect columns. Materials show preview spheres. Lights and Environments have their own sections.

Green Add Button

Bright green + Add Item pops off the toolbar. Primary action should be the most visible button.

Root vs Nested Body Colors

Root SdfBodies (depth 0) are amber ◆. Nested SdfBodies (depth 1+) are blue ◆. Immediate visual distinction.

Prim Colors = Boolean Op

Each prim icon is colored by its operation: green = union, red = subtract, blue = intersect, violet = smooth. You see the boolean structure at a glance.

Camera = Distinctive

Camera gets a warm gold ⬤ filled icon — immediately recognizable, never confused with lights or meshes.

Tree Connector Lines

Colored by scope depth. Root scope = amber lines, nested = blue, deep = violet. Lines + colors work together to show hierarchy.
