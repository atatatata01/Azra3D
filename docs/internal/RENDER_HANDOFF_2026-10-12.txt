WHAT WAS FIXED IN WGSL / HOST CODE
---------------------------------
1. Sampling: graphics/src/pathtrace_tri_entry.wgsl pt_r2 now uses the existing
integer PCG hash, 24-bit float conversion, avoiding large-f32 fract precision
collapse at high frame/pixel IDs that produced correlated stripe patterns.
2. Accumulation: new graphics/src/pt_progressive.wgsl writes RAW RGBA32Float
history, independent of FP16 display/denoising. No old 2048 history cap.
Actual sample counts weight variable-SPP batches. Per-pixel Welford moments
measure per-sample variance, not change in successive frame means.
Binding 60 = RGBA32Float storage output; 61 = RW vec4 moments array.
Moments are [luminance_mean, M2, sample_count, padding]. Reset never reads old
NaN/uninitialized history. Raw history -> next history copies, NOT display -> raw.
3. Reprojection: graphics/src/pt_reproject.wgsl carries FP32 color + conservative
moments; invalid/disoccluded samples clear moments. Separate color and ReSTIR
uniform buffers prevent queue.write_buffer last-write overwrite within a submit.
4. Denoising: variance-guided a-trous, geometry-plane depth/albedo/normal edge
weights. Removed unconditional disable after 96 frames. Per-pass uniform values
are uploaded once to a cached 128-byte buffer and encoded copies precede each
pass. No per-pass submit/allocation. Full/half denoiser targets remain FP16 display.
5. Estimator stability: idle full PT uses classic unidirectional NEE; no ReSTIR DI
or GI cache bias in full mode. Interactive mode retains reuse. Full bounce target
does NOT change with age or frame budget; budget can change SPP. Interactive can
reduce bounce count. Added PT_INTERACTIVE override and STATIC source variants.
6. Timing: app_gpu/src/gpu_timestamps.rs PASS_PATH_TRACE=18, RAII encoder interval,
actual asynchronous GPU duration. No CPU encode-time feedback as GPU cost.
Only written timestamp slots are resolved (unwritten NVIDIA queries lose device).
7. Cold pipeline: one in-flight background PT warmup, capped result drain, scheduler
admission. Actual raster draft while compiling; no fake accumulated samples.
Pipeline/resolution latch through interaction + eight-frame cooldown.
Removed incompatible raster/HDR soft history seeding in PT path.
