Owner decision: collapse the voxel/surface brush duality to **ONE surface (vertex-displacement) brush system**, Blender as target and feel. Voxel demoted to substrate ops (voxelize / explicit Remesh / booleans) — the Blender/DynaMesh shape. NO greenfield rewrite (audit: 8-12 sessions vs 4-5, rebuilds working undo/save/symmetry, anti-precedent).

- **>512³ exception (documented, fail-closed):** objects >512³ cannot mesh-display (Display Invariant) → they keep the density brush path as a documented legacy mode UNTIL high-res mesh display exists. Do not delete density kernels while this exception lives (Gate 4 parks, not deletes).

### Gate 4 — Park the density brush system

- Update BRUSH_SYSTEM_ARCHITECTURE.md to reflect surface-primary.
